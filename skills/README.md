# Skill Pack

В системе оставлены только два основных skill-источника.

## 01 — Hallmark

Источник: https://www.usehallmark.com/

Главный визуальный слой системы: защита от шаблонного AI-вида, намеренная композиция, характерная типографика, асимметрия, визуальная идентичность, сдержанное движение и отказ от повторяющихся макроструктур.

## 02 — Refactoring UI

Источник: https://skills.wondel.ai/skills/refactoring-ui/

Главный слой визуальной доводки: иерархия, spacing scale, типографика, цвет, глубина, композиция и системное устранение визуального шума.

## Правило

Никаких других skills в Website Factory System не используется. Hallmark отвечает за характер и визуальную систему. Refactoring UI отвечает за иерархию и доводку интерфейса.
