# Skill Pack

Кураторский набор приёмов для Website Factory System.

## Источники

- `sevzq/screenshot-to-html` — screenshot → semantic HTML + render/compare/refine + interaction verification. MIT.
- `Enixes/astra-frontend-design` — reference-to-code, art direction, responsive behavior, motion, accessibility and visual QA.
- `PaulRBerg/agent-skills` — frontend-design workflow: subject-specific direction, anti-default critique, rendered verification.
- `greensock/gsap-skills` — official GSAP skills for core animation, timelines, ScrollTrigger, plugins and performance. MIT.

Мы не копируем чужие репозитории целиком. Здесь находятся адаптированные workflow-контракты и ссылки на первоисточники. Приоритет — лицензия и оригинальный репозиторий.
