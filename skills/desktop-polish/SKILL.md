# Desktop Polish

Run after the architecture has been implemented.

## Inspect

- container width and gutters
- vertical rhythm
- hero composition
- heading/body scale and wrapping
- section transitions
- image crop and focal point
- cards and repeated patterns
- backgrounds, gradients, borders and shadows
- button hierarchy and states
- footer alignment

## Correction order

1. composition
2. spacing and dimensions
3. typography
4. imagery
5. color/contrast
6. surface polish
7. interactions

Use tokens and component rules; do not patch isolated elements with contradictory one-off values.

## PASS
Desktop looks intentionally art-directed at the target viewport(s), with no visible overlap, broken alignment, awkward wrapping or unfinished surfaces.
