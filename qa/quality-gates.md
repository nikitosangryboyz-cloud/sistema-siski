# Quality Gates

## Gate 01 — Reference
- [ ] target viewport identified
- [ ] design tokens extracted
- [ ] semantic structure implemented
- [ ] render/compare/refine completed
- [ ] major visual mismatch resolved

## Gate 02 — Architecture
- [ ] niche-specific structure
- [ ] truthful content model
- [ ] CTA map
- [ ] required assets identified

## Gate 03 — Desktop
- [ ] hierarchy
- [ ] spacing
- [ ] typography
- [ ] imagery
- [ ] color/contrast
- [ ] shadows/radii/gradients
- [ ] no visible defects

## Gate 04 — Responsive
- [ ] 375/390/414/430
- [ ] 768/820
- [ ] 1024
- [ ] desktop regression check
- [ ] no overflow/clipping

## Gate 05 — Production
- [ ] motion verified
- [ ] reduced-motion verified
- [ ] console clean
- [ ] assets and links valid
- [ ] accessibility baseline
- [ ] SEO baseline
- [ ] code cleaned

Only a passed gate may unlock the next stage.
