# Website Factory System

Система создания production-ready сайтов по референсу и тематике.

## Pipeline

1. **Stage 1 — Reference → HTML**  
   Восстановление визуального языка референса: layout, typography, colors, spacing, imagery, components.

2. **Stage 2 — Business Architecture**  
   Перевод визуальной системы в полноценную структуру сайта под конкретную нишу и бизнес-задачу.

3. **Stage 3 — Desktop Polish**  
   Полировка desktop-версии до production-ready состояния: композиция, типографика, цвета, тени, фоны, градиенты, spacing и QA.

4. **Stage 4 — Responsive**  
   Полноценная адаптация под tablet и mobile без деградации desktop-версии.

5. **Stage 5 — Motion & Production**  
   Анимации, smooth scroll, interactions, performance, code cleanup, accessibility, SEO и финальный QA.

## Core rules

- Reference design language is preserved unless an explicit decision changes it.
- Content architecture is created for the target niche, not copied mechanically from the reference.
- Desktop is polished before responsive work begins.
- Responsive work must not break desktop.
- Animation is purposeful and restrained.
- Avoid generic AI-generated visual patterns and repetitive template blocks.
- Every stage has its own QA and PASS criteria.
