# Stage 3 — Desktop Polish

## Goal
Довести desktop-версию до уровня готового к публикации интерфейса.

## Responsibilities
- audit every section from top to bottom
- fix layout, spacing and alignment
- tune typography hierarchy and wrapping
- refine colors, gradients, backgrounds, borders and shadows
- correct image cropping and visual balance
- remove visual inconsistencies and accidental repetition
- verify interactions and states on desktop

## Output
- polished desktop page
- stable design-system tokens
- no obvious visual defects

## Do not
- redesign the whole concept without cause
- start mobile-specific restructuring
- leave known visual defects for later

## QA / PASS
PASS only when the desktop version looks intentionally designed at every viewport in the desktop target range and no visible defects remain.
