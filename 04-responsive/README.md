# Stage 4 — Responsive

## Goal
Создать полноценную tablet/mobile-адаптацию без поломки готового desktop.

## Responsibilities
- design responsive behavior, not simple scaling
- establish breakpoint strategy
- adapt navigation, grids, cards, typography and media
- reorder sections where mobile UX requires it
- handle tables, catalogs, forms, sticky elements and horizontal content
- verify tablet and mobile intermediate states

## Output
- desktop preserved
- tablet layout
- mobile layout
- responsive behavior documented where useful

## Do not
- blindly shrink desktop values
- break desktop to fix mobile
- add endless breakpoint overrides without structure

## QA / PASS
PASS only when the page is coherent and visually intentional across desktop, tablet, mobile and intermediate widths, with no overflow or broken interaction states.
