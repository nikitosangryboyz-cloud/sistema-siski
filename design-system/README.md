# Design System Contract

Stage 1 establishes the visual truth. Later stages consume it rather than silently replacing it.

## Required artifacts

- `tokens.json` — colors, typography, spacing, radii, shadows, layout constraints.
- `reference.md` — visual interpretation and composition rules.
- `locked.md` — decisions that later stages must preserve unless a deliberate exception is recorded.

## Lock rule

After Stage 1 PASS, changes to the core visual language require an explicit reason in the project changelog.
