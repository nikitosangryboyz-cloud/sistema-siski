# Stage 5 — Motion & Production

## Goal
Довести сайт до production-ready состояния: motion, interactions, performance и финальный engineering QA.

## Responsibilities
- add purposeful scroll and reveal animations
- configure smooth scrolling where appropriate
- add micro-interactions and state transitions
- tune hero and section motion without visual noise
- clean HTML/CSS/JS structure
- remove unnecessary code and dependencies
- verify assets, paths, console errors and loading behavior
- check accessibility basics, metadata and SEO foundations

## Output
- polished motion system
- clean production code
- final QA report
- publication-ready site

## Do not
- add animation just because a library is available
- sacrifice performance for effects
- rewrite stable sections without a concrete reason

## QA / PASS
PASS only when motion is smooth and purposeful, the console is clean, assets resolve correctly, code is maintainable, responsive behavior remains intact, and no known release-blocking issues remain.
