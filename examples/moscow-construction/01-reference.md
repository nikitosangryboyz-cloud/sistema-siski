# Stage 01 — Reference → HTML

## Source

Пользовательский референс: мобильный скриншот 362×524 px.

## Visual DNA

**Composition:** thin header → oversized title → full-width architectural image → facts grid → section title → two-column about block.

**Typography:** black neo-grotesk/sans, uppercase display headline, compact navigation, very large numeric statistics, small metadata labels.

**Color:** paper white `#FFFFFF`, near-black `#111111`, neutral gray dividers around `#D7D7D7`, muted copy around `#686868`.

**Geometry:** 1px rules, almost no rounded UI, rectangular image crops, generous whitespace, asymmetrical editorial grid.

**Image treatment:** real architectural photography, no gradients used as a design crutch, image carries the emotional weight.

## Reconstruction decisions

1. Keep the title over the image instead of placing it in a conventional hero card.
2. Preserve the stat-grid rhythm but increase the number of useful facts for the target business.
3. Preserve `section title + number` as a recurring navigation cue.
4. Replace the reference's exact content with construction-specific content while retaining visual grammar.
5. Avoid generic rounded cards, pills, glassmorphism and gradient headings.

## Stage 01 PASS

The visual system is locked for later stages: white/black editorial construction, thin rules, large type, architectural imagery, sparse UI.
