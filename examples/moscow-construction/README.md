# АРХФОРМ — строительная компания в Москве

Реализация по `Website Factory System` на основе предоставленного мобильного референса.

## Pipeline status

| Stage | Status | Результат |
|---|---|---|
| 01 Reference → HTML | PASS | Визуальный язык референса восстановлен |
| 02 Business Architecture | PASS | Архитектура адаптирована под строительство домов |
| 03 Desktop Polish | PASS | Desktop-система собрана как отдельная production-композиция |
| 04 Responsive | PASS | Tablet/mobile — отдельная рекомпозиция |
| 05 Motion & Production | PASS | GSAP motion, interaction, accessibility и финальный QA |

## Что перенесено из референса

- тонкий технический header;
- белое поле и чёрная типографика без декоративного AI-шума;
- огромный condensed/neo-grotesk заголовок, заходящий на фотографию;
- архитектурная фотография как главный визуальный носитель;
- статистика через тонкую сетку и крупные цифры;
- секционные заголовки в формате `название + номер`;
- большие поля вокруг контента;
- линейная типографическая иерархия вместо набора карточек;
- крупные фото проектов с короткими подписями.

## Что изменено под нишу

Референс не копируется механически. Для строительной компании добавлены: услуги, проекты, процесс работы, инженерия, комплектация и CTA от участка. Цифры и факты в демо-контенте являются заменяемыми placeholder-данными и не должны публиковаться как подтверждённые факты без проверки.

## Run

Открыть `index.html` локально или опубликовать папку как GitHub Pages site.

### QA

- desktop: 1440 / 1280 / 1024;
- tablet: 900 / 768;
- mobile: 390 / 375 / 360;
- проверить горизонтальный overflow;
- проверить меню и якоря;
- проверить `prefers-reduced-motion`;
- проверить консоль и загрузку изображений;
- заменить demo-тексты, телефон, email и фото перед публикацией.
