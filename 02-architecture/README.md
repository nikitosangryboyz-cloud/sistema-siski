# Stage 2 — Business Architecture

## Goal
Превратить визуальную систему референса в полноценный сайт для заданной ниши.

## Input
- Stage 1 visual system
- target niche
- business information
- required services/products/contacts

## Responsibilities
- research and define the user's actual information needs for the niche
- build page and section architecture
- define CTA hierarchy
- define content modules, catalog structures, forms and conversion paths
- preserve the Stage 1 visual language while adapting content architecture

## Output
- complete section map
- content model
- component inventory
- full-page content structure ready for desktop polish

## Do not
- copy the reference's content structure blindly
- replace only text while leaving irrelevant sections
- invent business facts
- destroy the established visual language without a documented reason

## QA / PASS
PASS only when every required business question is covered, the page has a coherent conversion path, and every section has a clear purpose.
